UI 부품 견본

새로 만드는 버튼·탭·칩·입력칸·날짜선택은 이 모양만 씁니다. 규칙은 AGENTS.md "UI 부품 규칙"에 있습니다.

버튼 .ui-btn

한 영역에 primary 는 1개만 둡니다. 나머지는 기본·soft·ghost 로 둡니다.

탭 .ui-tabs + .ui-tab

보기 전환(주간/월간, 판매처 등)에 씁니다. UI.tabs(상자, 바뀔때함수)

선택: week

칩 .ui-chip

여러 개를 켰다 껐다 하는 필터에 씁니다. 켜짐은 aria-pressed="true"

입력칸 .ui-field

input·select 역할 버튼 모두 같은 모양입니다.

날짜선택 UI.datePicker()

<input type="date"> 나 새 달력을 만들지 말고 이것을 씁니다.
