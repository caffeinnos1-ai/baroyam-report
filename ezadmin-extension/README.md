# 김비서AI 확장프로그램 (크롬 확장 · 예전 이름 "바로얌 재고 수집")

대시보드 **판매·재고 > 재고현황 > 어드민 수집** 단추가 쓰는 확장 프로그램입니다.
평소에는 VPS가 매일 07:00·16:30 이지어드민에 자동 로그인해 재고를 채우고(`caffeinnos-automation/inventory_report.js`),
로봇 검사로 자동 로그인이 막힌 날에는 이 단추로 사람이 **로그인만** 해서 가져옵니다.

## 설치 (PC마다 처음 한 번)
1. 크롬 주소창에 `chrome://extensions` → 오른쪽 위 **개발자 모드** 켜기
2. **압축해제된 확장 프로그램 로드** → 이 폴더(`report-webapp\ezadmin-extension`) 고르기
3. 대시보드를 새로고침

코드를 고친 뒤에는 `chrome://extensions` 에서 이 확장의 **새로고침(↻)** 을 누릅니다.

## 동작
1. 대시보드 단추 → `dashboard.js` → `background.js` 가 이지어드민 현 재고조회(I100)를 **최소화된 창**으로 엽니다(누를 때 창이 아주 잠깐 보였다 내려감).
   1.3.0~1.4.0 에는 창 대신 안 보이는 탭(접힌 탭 묶음)에서 돌렸는데, 크롬이 안 보이는 탭을 거의 멈추다시피 늦춰 사람이 그 탭을 눌러야 끝났습니다 → 1.4.1 에 되돌림.
2. 로그인이 풀려 있으면 로그인 화면으로 가면서 그 창을 앞으로 띄웁니다 · 사람이 로그인하면 창은 다시 내려갑니다.
   수집 창에서는 이지어드민 안내창(alert·confirm)을 띄우지 않고 넘기고(확인창은 "확인"), 내용은 대시보드 안내 줄에 보입니다 · 사람이 여는 이지어드민 창은 그대로입니다.
3. `ezadmin.js` 가 로그인을 알아채고 현 재고조회로 가서 **검색(F2)** → 표(상품코드·공급처·상품명·정상재고·유통기한)를 읽습니다.
4. 표를 대시보드로 넘기면 대시보드가 로그인한 계정으로 `app_settings` 의 `inventory_v1` 에 저장하고(`via:'manual'`), 이지어드민 창을 닫습니다.
   실패하면 이지어드민 창을 앞으로 띄워 둡니다(화면 위 빨간 띠에 이유).

### 당일판매 (1.2.0~)
당일판매현황 탭에서 어드민 수집을 누르면 **당일판매분요약표 주소(`template40.htm?template=F304`)를 바로** 열어(1.5.0~ · 예전엔 메뉴를 눌러 넘어가다 자주 막힘)
검색하고, 상품명·당일수량·정상재고와 주문수량, 위 "항목 | 개수" 상자의 **송장수량**(슬랙 보고의 출고 숫자와 같음)을 읽어 넘깁니다.
로그인 뒤 첫 화면으로 가면 다시 요약표 주소로 보냅니다. 송장수량을 못 읽은 날은 첫 화면의 "배송(금일)" 숫자를 대신 씁니다.
대시보드는 VPS(`daily_report.js`)와 같은 규칙(재고자동화.xlsx 매핑 `daily_sales_names_v1` → 맨 앞 `[브랜드]`)으로 `daily_sales_v1` 에 저장합니다.
평소에는 VPS 가 11:00·14:00(ERP 만)·16:15(슬랙과 함께) 채웁니다.

확장은 대시보드의 "어드민 수집"이 연 창에서만 움직이고, 평소에 여는 이지어드민 창은 건드리지 않습니다.
상품 한 줄 만들기(브랜드·유통기한 나누기)는 대시보드(`ivToItem`)가 VPS와 같은 규칙으로 합니다.

### 쿠팡윙 수집 (1.6.0~ · 2026-11-19)
판매채널 › 쿠팡 › 쿠팡광고성과 배너 오른쪽 **쿠팡윙 수집** 단추가 씁니다.
1. `background.js` 가 쿠팡 광고센터(`advertising.coupang.com`)를 최소화된 창으로 엽니다 · 로그인 화면이면 창을 앞으로 띄웁니다.
2. `coupang.js` 가 보고서 화면에서 **글자로** 조건을 찾아 고릅니다: 기간 이번 달 1일~오늘 · 일별 · 모든 캠페인 ·
   캠페인·광고그룹·상품·키워드 · 클릭이 발생한 키워드만 → 보고서 만들기 → 다 만들어지면 다운로드.
3. 내려받기가 끝나면 `background.js`(downloads 권한)가 그 파일을 읽어 대시보드로 넘기고, 대시보드가 `coupang_ads_v1:<달>` 에 저장한 뒤 쿠팡 창을 닫습니다.
4. 어느 단계든 화면에서 찾지 못하면 파란 띠로 "직접 만들고 다운로드만 눌러 달라"고 알리며 창을 앞으로 띄웁니다 ·
   사람이 다운로드를 눌러도 같은 길로 ERP 에 들어갑니다(수집 창을 연 뒤 20분 안).
쿠팡 광고센터 화면은 아직 실제로 맞춰 보지 못했습니다 · 처음 몇 번은 사람이 지켜보며 못 찾은 단계를 알려 주세요.

1.6.1 · 실제 화면(보고서 주소 `/marketing-reporting/billboard/reports/pa`)에 맞춤: 그 주소로 바로 열고, 캠페인 선택 목록을 열어 전체 선택(없으면 보이는 캠페인 모두),
기간 구분·보고서 구조는 라디오, 클릭 발생 키워드만은 체크칸으로 고른 뒤 보고서 만들기. 오른쪽 목록에서 **기간(이번 달 1일 - 오늘)·일별·키워드** 줄이
"완료"가 되고 다운로드 단추가 생기면 누릅니다(최대 15분 · 목록이 안 바뀌면 40초마다 화면을 새로 엶). 10만 줄이 넘어 TAB 텍스트(.txt)로 받아도 읽습니다.
