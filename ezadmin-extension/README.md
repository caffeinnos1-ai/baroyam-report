# 바로얌 재고 수집 (크롬 확장)

대시보드 **판매·재고 > 재고현황 > 어드민 수집** 단추가 쓰는 확장 프로그램입니다.
평소에는 VPS가 매일 07:00·16:30 이지어드민에 자동 로그인해 재고를 채우고(`caffeinnos-automation/inventory_report.js`),
로봇 검사로 자동 로그인이 막힌 날에는 이 단추로 사람이 **로그인만** 해서 가져옵니다.

## 설치 (PC마다 처음 한 번)
1. 크롬 주소창에 `chrome://extensions` → 오른쪽 위 **개발자 모드** 켜기
2. **압축해제된 확장 프로그램 로드** → 이 폴더(`report-webapp\ezadmin-extension`) 고르기
3. 대시보드를 새로고침

코드를 고친 뒤에는 `chrome://extensions` 에서 이 확장의 **새로고침(↻)** 을 누릅니다.

## 동작
1. 대시보드 단추 → `dashboard.js` → `background.js` 가 이지어드민 현 재고조회(I100)를 대시보드 창 안의 **접힌 탭 묶음**("바로얌 수집")에 엽니다 · 새 창을 만들지 않아 번쩍이지 않습니다(1.3.0~ · 예전 최소화 창은 잠깐 보였다 사라졌음).
2. 로그인이 풀려 있으면 그 탭을 따로 창으로 꺼내 앞에 띄웁니다 · 사람이 로그인하면 다시 접힌 묶음으로 돌아가고 그 창은 닫힙니다.
3. `ezadmin.js` 가 로그인을 알아채고 현 재고조회로 가서 **검색(F2)** → 표(상품코드·공급처·상품명·정상재고·유통기한)를 읽습니다.
4. 표를 대시보드로 넘기면 대시보드가 로그인한 계정으로 `app_settings` 의 `inventory_v1` 에 저장하고(`via:'manual'`), 이지어드민 탭을 닫습니다.
   실패하면 이지어드민 탭을 창으로 꺼내 앞에 띄워 둡니다(화면 위 빨간 띠에 이유).

### 당일판매 (1.2.0~)
당일판매현황 탭에서 어드민 수집을 누르면 같은 창이 로그인 확인 뒤 **정산통계 > 당일판매분요약표**로 넘어가 검색하고,
상품명·당일수량·정상재고와 주문수량을 읽어 넘깁니다. 로그인 직후 첫 화면을 거치면 "배송(금일)" 숫자도 챙깁니다(이미 로그인돼 있던 날은 주문수량만).
대시보드는 VPS(`daily_report.js`)와 같은 규칙(재고자동화.xlsx 매핑 `daily_sales_names_v1` → 맨 앞 `[브랜드]`)으로 `daily_sales_v1` 에 저장합니다.
평소에는 VPS 가 11:00·14:00(ERP 만)·16:15(슬랙과 함께) 채웁니다.

확장은 대시보드의 "어드민 수집"이 연 창에서만 움직이고, 평소에 여는 이지어드민 창은 건드리지 않습니다.
상품 한 줄 만들기(브랜드·유통기한 나누기)는 대시보드(`ivToItem`)가 VPS와 같은 규칙으로 합니다.
